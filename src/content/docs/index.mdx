EVSuite is a collection of independent apps. Install only the ones that solve a problem
for you; you do not need the complete suite.

## Start in three steps

1. [Choose the apps that match your needs](/EVSuite/start/overview/).
2. [Read the safety information](/EVSuite/start/safety/).
3. [Open Android Settings](/EVSuite/tutorial/settings-access/) and follow the installation guide.
