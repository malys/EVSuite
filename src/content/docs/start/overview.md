You do not need to install every MG4Suite app. Start with the result you want:

| I want to… | Install | What it changes |
| --- | --- | --- |
| Adjust supported vehicle settings and save profiles | [MG4 Control](/MG4Suite/apps/control/) | Can read and change vehicle settings while parked |
| Run actions automatically when conditions are met | [MG4 Tasker](/MG4Suite/apps/tasker/) | Can run local actions and supported vehicle changes |
| Send live vehicle data to A Better Routeplanner | [MG4 ABRP Uploader](/MG4Suite/apps/abrp/) | Reads telemetry and sends it to ABRP; never changes the vehicle |
| Replace the original home screen with large app shortcuts | [MG4 Simple Launcher](/MG4Suite/apps/simple-launcher/) | Changes which app Android opens as Home; no vehicle access |
| Open an app or go Back with a bottom-edge swipe | [MG4 Swipe Launcher](/MG4Suite/apps/swipe-launcher/) | Uses accessibility and overlay access; no vehicle access |

## Common combinations

- **ABRP only:** install MG4 ABRP Uploader.
- **Manual vehicle controls:** install MG4 Control.
- **Automation:** install MG4 Tasker. Add MG4 Control only if a rule needs to apply a
  profile saved in Control.
- **Simpler navigation:** install MG4 Simple Launcher. Add MG4 Swipe Launcher if you also
  want bottom-edge shortcuts.

## Before downloading

The apps target the SAIC MG4 head unit running Android Automotive OS 9. Available vehicle
features differ between firmware versions. Screenshots show the interface in an emulator;
they do not guarantee that every feature works on your car.
